# file-reader-and-text-editor

This app is based on a task I received during a job interview.

Since this was quite challenging in the moment (mainly because of time-pressure), I decided to program it again by myself without the help of AI tools.

In addition, I decided to extend the task, and make a simple REST app.

Users can now upload their .txt files with an additional .txt containing the word pairings that are going to be replaced in the text.

For this project, Java and Spring Boot were used for the Backend, while Vue and Vite were used for the Frontend.
